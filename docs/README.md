## Safety in one paragraph

Scan only reads. Sort copies and checks every copy against its checksum;
originals stay untouched. Quarantine moves originals aside but deletes
nothing. Only **Purge** deletes, only quarantined files older than the grace
period, only after you confirm a separate backup, and never a file whose
library copy no longer checks out. Outbird backs up the Thunderbird profile
before writing into it and writes nothing if its validation fails.
